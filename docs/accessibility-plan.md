# Accessibility plan

- Use the document language, a descriptive page title, semantic `header`, `nav`, `main`, `section`, `form`, and table markup.
- Every form input has a visible associated label.
- Keyboard focus remains visible with `:focus-visible`; interactive controls must work without a mouse.
- Use descriptive accessible names for icon-only buttons and announce errors/status messages with live regions.
- Preserve logical heading order and sufficient contrast across dark and light themes.
- Respect `prefers-reduced-motion`.
- Test the mobile navigation, modal, form, search, import/export, and keyboard shortcuts with keyboard only.
- Manual audit checklist: Tab/Shift+Tab order, Enter/Space activation, Escape dismissal, browser zoom at 200%, narrow viewport, and screen-reader labels/live announcements.
